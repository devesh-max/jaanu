BESTIE — UPDATED WEBSITE WITH MUSIC + QUIZ ARCADE

WHAT'S INCLUDED
- Music player dock on every page, using music.mp3.
- No separate music.html page.
- Quiz Arcade with two 10-question quizzes:
  1. Guess What I Like
  2. How Well Do You Know Me?
- One mark per correct answer, 10 marks per quiz.
- Best scores saved in the browser using localStorage; total scoreboard is out of 20.
- Existing letters, scrapbook, surprise, reasons, wish list, secret note and finale remain. The Timeline page has been removed.

UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. Open the jaanu GitHub repository.
3. Upload ALL files and folders from inside this ZIP to the repository root.
4. Replace old files when GitHub asks. Make sure music.mp3, quiz-data.js, script.js and style.css are uploaded.
6. Settings > Pages > Deploy from a branch > main > /(root) > Save.
7. Wait for deployment, then open https://devesh-max.github.io/jaanu/

MUSIC
- The uploaded track has been converted to MP3 for broad browser support.
- The player appears at the bottom of every page.
- Tap Play once to start. Browsers can block automatic playback.
- The player attempts to remember the playback position between page changes, but a browser may require another Play tap after navigation.

PERSONALISE THE QUIZZES
Open quiz-data.js in a text editor.
Each quiz has 10 questions. For each question:
- Edit question to suit your game.
- Edit the four options.
- Set answer to the correct option number: 0 = first option, 1 = second, 2 = third, 3 = fourth.
The starter answers are examples only. Set them to the real answers before sharing.
Each correct answer = 1 mark. The total best score across both quizzes is out of 20.
Scores are saved on the visitor's browser and do not sync between different devices.
